Supports memory cards (.ps2 .mcd .mc2 .bin) and exported saves (.cbs .psu .sps read/write · .max .psv read-only).
Everything runs on your device — the save file is never uploaded. Edits recompute the gamedata checksum (and memory-card ECC) so the game loads the save normally. You download an edited copy; your original file is untouched.
